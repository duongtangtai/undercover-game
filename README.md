# Undercover Game

I made this repo, so you don't have to. Have fun with your friends!

Static single-player pass-and-play Undercover game for local parties. Built with Vite, TypeScript, and Phaser.

## Play Locally

```powershell
npm install
npm run dev
```

Open `http://localhost:5173`.

For mobile testing on the same Wi-Fi, open `http://<your-computer-lan-ip>:5173`.

## Build

```powershell
npm run build
npm run preview
```

Production output is generated in `dist/`, ready for Vercel static deploy.
